# Lolo Seasons (фан-мод для NeoForge 1.21.1)

Фан-мод по сюжетным сезонам Лололошки. Не связан с автором сезонов.

## Сборка и запуск
Нужна Java 21.
- `./gradlew runClient` — запустить игру с модом (первый запуск долгий: скачивается Minecraft)
- `./gradlew build` — собрать jar, он появится в `build/libs/`

## Что внутри
Материалы: Осколок Искры, Осколок Времени, Слиток Архея, Уголёк Тринадцати Огней.
Блоки: Руда Архея (генерируется в Верхнем мире, y от -60 до 30), Блок Архея, Жаровня Тринадцати Огней (свет 13, анимированный огонь).
Снаряжение: Меч и Кирка Архея, Посох Мироходца (блинк), Часы Конца Времени (следующее утро),
Смартфон (координаты/время/биом), Амулет Скарабея (баффы), Уточка (коллекционная).
NPC (яйца призыва в креативе): Странник-Мироходец (обмен 4 осколка Искры на 2 осколка Времени) и Автоматон Хенфорта.
Настройки: `config/lolo_seasons-common.toml`.

## Где что менять
- `item/ModItems.java`, `block/ModBlocks.java`, `entity/ModEntities.java` — регистрация
- `src/main/resources/assets/lolo_seasons/` — текстуры, модели, переводы (ru_ru, en_us)
- `src/main/resources/data/lolo_seasons/` — рецепты, лут, генерация руды
